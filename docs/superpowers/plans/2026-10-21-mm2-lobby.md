# MM2 Lobby Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Windows desktop lobby that lists which friends are online over a ZeroTier network, lets one of them claim the host role, and starts Midtown Madness 2.

**Architecture:** Every copy of the app broadcasts a small UDP announcement on the ZeroTier network every 2 seconds and listens for the others, so the app runs no server. All logic lives in `Mm2Lobby.Core`, which targets `net10.0` and contains no WPF and no Windows-only API, so the whole test suite runs on macOS. Two thin Windows projects hold the registry, DISM, firewall, process, and WPF code.

**Tech Stack:** .NET 10, C#, `System.Text.Json`, `System.Net.Sockets`, WPF, xunit.

**Spec:** `docs/superpowers/specs/2026-10-21-mm2-lobby-design.md`

## Global Constraints

Every task's requirements implicitly include this section.

- `net10.0` for `src/Mm2Lobby.Core` and `tests/Mm2Lobby.Core.Tests`. `net10.0-windows` for `src/Mm2Lobby.Windows` and `src/Mm2Lobby.App`. The SDK is .NET 10, because .NET 8 leaves long-term support in November 2026. Every API this plan uses, including `System.Net.IPNetwork`, arrived in .NET 8 and remains in .NET 10.
- `Mm2Lobby.Core` must not reference WPF, the registry, DISM, `System.Diagnostics.Process`, or any other Windows-only API. Every such call goes behind an interface that `Mm2Lobby.Windows` implements. This is what keeps the tests runnable on macOS.
- Every test lives in `tests/Mm2Lobby.Core.Tests`. No test needs Windows, a real network, or a real ZeroTier install.
- `<Nullable>enable</Nullable>` and `<TreatWarningsAsErrors>true</TreatWarningsAsErrors>` in every project.
- UDP port: `48200`. Announcement protocol version: `1`.
- Refresh cycle: 2 seconds. Peer expiry: 6 seconds.
- Maximum player name length: 32 characters.
- JSON on the wire and on disk uses camelCase property names.
- IPv4 only. The app ignores IPv6 addresses that ZeroTier assigns.
- End every commit message with a `Co-Authored-By:` line naming the model that
  wrote that commit — the attribution line your own session gives you, not a
  fixed name copied from here. Tasks run on different models, so the trailers
  across this branch differ, and that is correct: the trailer records who did
  the work. Revision 1 of this plan hardcoded `Claude Opus 5`, which would have
  made every subagent claim authorship it did not have.

- Tasks 1 to 7 build and test on macOS. Tasks 8 and 9 need a Windows machine with the .NET 10 SDK. Do not start task 8 before a Windows machine is available.

```csharp
        var key = $"{fileName} {arguments}";
```

`src/Mm2Lobby.Core/ZeroTier/ZeroTierClient.cs`:

```csharp
using System.Net;
using System.Net.Sockets;
using System.Text.Json;
using Mm2Lobby.Core.Processes;

namespace Mm2Lobby.Core.ZeroTier;

/// <summary>
/// Reads the local ZeroTier state. Every method answers null or an empty
/// result rather than throwing, because a missing or upgraded zerotier-cli is
/// an expected condition.
/// </summary>
public sealed class ZeroTierClient : IZeroTierClient
{
    private static readonly IReadOnlyDictionary<string, LinkQuality> NoPeers =
        new Dictionary<string, LinkQuality>(StringComparer.OrdinalIgnoreCase);

    private readonly IProcessRunner _runner;
    private readonly string _executable;

    public ZeroTierClient(IProcessRunner runner, string executable = "zerotier-cli")
    {
        _runner = runner;
        _executable = executable;
    }

    public async Task<ZeroTierStatus?> GetStatusAsync(CancellationToken ct)
    {
        var json = await ReadJsonAsync("-j info", ct);
        if (json is null || json.RootElement.ValueKind != JsonValueKind.Object)
        {
            json?.Dispose();
            return null;
        }

        using (json)
        {
            var root = json.RootElement;
            var nodeId = root.TryGetProperty("address", out var address)
                ? address.GetString()
                : null;
            if (string.IsNullOrWhiteSpace(nodeId)) return null;

            var online = root.TryGetProperty("online", out var flag)
                && flag.ValueKind == JsonValueKind.True;

            return new ZeroTierStatus(online, nodeId.ToLowerInvariant());
        }
    }

    public async Task<ZeroTierNetwork?> GetNetworkAsync(string networkId, CancellationToken ct)
    {
        var json = await ReadJsonAsync("-j listnetworks", ct);
        if (json is null || json.RootElement.ValueKind != JsonValueKind.Array)
        {
            json?.Dispose();
            return null;
        }

        using (json)
        {
            foreach (var entry in json.RootElement.EnumerateArray())
            {
                var id = entry.TryGetProperty("nwid", out var nwid) ? nwid.GetString() : null;
                if (!string.Equals(id, networkId, StringComparison.OrdinalIgnoreCase)) continue;

                var status = entry.TryGetProperty("status", out var s)
                    ? s.GetString() ?? string.Empty
                    : string.Empty;

                var (address, prefix) = FirstIPv4(entry);
                return new ZeroTierNetwork(networkId.ToLowerInvariant(), status, address, prefix);
            }

            return null;
        }
    }

    public async Task<IReadOnlyDictionary<string, LinkQuality>> GetLinkQualityAsync(
        CancellationToken ct)
    {
        var json = await ReadJsonAsync("-j listpeers", ct);
        if (json is null || json.RootElement.ValueKind != JsonValueKind.Array)
        {
            json?.Dispose();
            return NoPeers;
        }

        using (json)
        {
            var map = new Dictionary<string, LinkQuality>(StringComparer.OrdinalIgnoreCase);
            foreach (var peer in json.RootElement.EnumerateArray())
            {
                var role = peer.TryGetProperty("role", out var r) ? r.GetString() : null;
                if (!string.Equals(role, "LEAF", StringComparison.OrdinalIgnoreCase)) continue;

                var nodeId = peer.TryGetProperty("address", out var a) ? a.GetString() : null;
                if (string.IsNullOrWhiteSpace(nodeId)) continue;

                map[nodeId.ToLowerInvariant()] =
                    HasLivePath(peer) ? LinkQuality.Direct : LinkQuality.Relayed;
            }

            return map;
        }
    }

    private async Task<JsonDocument?> ReadJsonAsync(string arguments, CancellationToken ct)
    {
        var result = await _runner.RunAsync(_executable, arguments, ct);
        if (!result.Succeeded || string.IsNullOrWhiteSpace(result.StandardOutput)) return null;

        try
        {
            return JsonDocument.Parse(result.StandardOutput);
        }
        catch (JsonException)
        {
            return null;
        }
    }

    private static (IPAddress? Address, int PrefixLength) FirstIPv4(JsonElement network)
    {
        if (!network.TryGetProperty("assignedAddresses", out var assigned)
            || assigned.ValueKind != JsonValueKind.Array)
        {
            return (null, 0);
        }

        foreach (var entry in assigned.EnumerateArray())
        {
            var text = entry.GetString();
            if (text is null) continue;

            var slash = text.IndexOf('/');
            if (slash <= 0) continue;

            if (!IPAddress.TryParse(text[..slash], out var address)) continue;
            if (address.AddressFamily != AddressFamily.InterNetwork) continue;
            if (!int.TryParse(text[(slash + 1)..], out var prefix)) continue;
            if (prefix is < 0 or > 32) continue;

            return (address, prefix);
        }

        return (null, 0);
    }

    private static bool HasLivePath(JsonElement peer)
    {
        if (!peer.TryGetProperty("paths", out var paths)
            || paths.ValueKind != JsonValueKind.Array)
        {
            return false;
        }

        foreach (var path in paths.EnumerateArray())
        {
            var active = path.TryGetProperty("active", out var a)
                && a.ValueKind == JsonValueKind.True;
            var expired = path.TryGetProperty("expired", out var e)
                && e.ValueKind == JsonValueKind.True;

            if (active && !expired) return true;
        }

        return false;
    }
}
```

`src/Mm2Lobby.Core/Peers/IPv4Math.cs`:

```csharp
using System.Buffers.Binary;
using System.Net;
using System.Net.Sockets;

namespace Mm2Lobby.Core.Peers;

/// <summary>
/// The IPv4 arithmetic that peer discovery needs. ZeroTier reports an address
/// and a prefix length; discovery needs the subnet, to decide which senders to
/// trust, and the broadcast address, to reach every member.
/// </summary>
public static class IPv4Math
{
    public static IPNetwork Subnet(IPAddress address, int prefixLength)
    {
        var raw = ToUInt32(address, prefixLength);
        var mask = Mask(prefixLength);
        return new IPNetwork(ToAddress(raw & mask), prefixLength);
    }

    public static IPAddress BroadcastAddress(IPAddress address, int prefixLength)
    {
        var raw = ToUInt32(address, prefixLength);
        var mask = Mask(prefixLength);
        return ToAddress((raw & mask) | ~mask);
    }

    private static uint ToUInt32(IPAddress address, int prefixLength)
    {
        if (address.AddressFamily != AddressFamily.InterNetwork)
        {
            throw new ArgumentException("The address must be IPv4.", nameof(address));
        }

        if (prefixLength is < 0 or > 32)
        {
            throw new ArgumentOutOfRangeException(
                nameof(prefixLength), prefixLength, "The prefix length must be 0 to 32.");
        }

        return BinaryPrimitives.ReadUInt32BigEndian(address.GetAddressBytes());
    }

    private static uint Mask(int prefixLength)
        => prefixLength == 0 ? 0u : uint.MaxValue << (32 - prefixLength);

    private static IPAddress ToAddress(uint value)
    {
        var bytes = new byte[4];
        BinaryPrimitives.WriteUInt32BigEndian(bytes, value);
        return new IPAddress(bytes);
    }
}
```

```csharp
using System.Net;

namespace Mm2Lobby.Core.Peers;

/// <summary>
/// Holds the peers heard recently and rejects everything else. The socket binds
/// to 0.0.0.0 to receive the directed broadcast, so the player's home network
/// can also reach the port. The subnet test is the authorisation boundary.
/// </summary>
public sealed class PeerTable
{
    public const int MaxPlayerNameLength = 32;

    private readonly TimeSpan _expiry;
    private readonly Func<DateTimeOffset> _clock;
    private readonly Dictionary<string, LivePeer> _peers = new(StringComparer.OrdinalIgnoreCase);
    private readonly object _gate = new();

    public PeerTable(TimeSpan expiry, Func<DateTimeOffset> clock)
    {
        _expiry = expiry;
        _clock = clock;
    }

    /// <summary>
    /// Validates one datagram and records it. Returns false when the datagram
    /// fails any rule, which the caller may ignore: a rejected datagram is a
    /// normal event, not an error.
    /// </summary>
    public bool Accept(ReadOnlySpan<byte> datagram, IPAddress source, IPNetwork allowed)
    {
        if (!allowed.Contains(source)) return false;

        var message = Announcement.TryParse(datagram);
        if (message is null) return false;
        if (message.Proto != Announcement.CurrentProto) return false;
        if (string.IsNullOrWhiteSpace(message.NodeId)) return false;
        if (string.IsNullOrWhiteSpace(message.Player)) return false;
        if (message.Player.Length > MaxPlayerNameLength) return false;
        if (!IPAddress.TryParse(message.Address, out var claimed)) return false;
        if (!claimed.Equals(source)) return false;

        var peer = new LivePeer(
            message.NodeId.ToLowerInvariant(),
            message.Player,
            source,
            message.Hosting,
            message.StartedAt,
            message.AppVersion,
            _clock());

        lock (_gate)
        {
            _peers[peer.NodeId] = peer;
        }

        return true;
    }

    public IReadOnlyList<LivePeer> GetLive()
    {
        var cutoff = _clock() - _expiry;

        lock (_gate)
        {
            return _peers.Values.Where(peer => peer.HeardAt > cutoff).ToList();
        }
    }
}
```

```csharp
using System.Net;
using System.Net.Sockets;

namespace Mm2Lobby.Core.Peers;

/// <summary>
/// Sends and receives announcements over UDP. It binds to 0.0.0.0 so that a
/// directed broadcast such as 10.147.17.255 arrives. PeerTable decides which
/// senders to trust.
/// </summary>
public sealed class UdpPeerTransport : IPeerTransport
{
    private UdpClient? _client;
    private CancellationTokenSource? _loop;
    private Task? _receive;

    public event Action<byte[], IPAddress>? DatagramReceived;

    public Task StartAsync(int port, CancellationToken ct)
    {
        if (_client is not null)
        {
            throw new InvalidOperationException("The transport has already started.");
        }

        var client = new UdpClient(AddressFamily.InterNetwork);
        client.Client.SetSocketOption(
            SocketOptionLevel.Socket, SocketOptionName.ReuseAddress, true);
        client.Client.Bind(new IPEndPoint(IPAddress.Any, port));
        client.EnableBroadcast = true;
        _client = client;

        _loop = CancellationTokenSource.CreateLinkedTokenSource(ct);
        _receive = ReceiveLoopAsync(client, _loop.Token);
        return Task.CompletedTask;
    }

    public async Task SendAsync(
        byte[] payload, IPAddress destination, int port, CancellationToken ct)
    {
        var client = _client
            ?? throw new InvalidOperationException("The transport has not started.");

        await client.SendAsync(payload, new IPEndPoint(destination, port), ct);
    }

    private async Task ReceiveLoopAsync(UdpClient client, CancellationToken ct)
    {
        while (!ct.IsCancellationRequested)
        {
            try
            {
                var received = await client.ReceiveAsync(ct);
                DatagramReceived?.Invoke(received.Buffer, received.RemoteEndPoint.Address);
            }
            catch (OperationCanceledException)
            {
                return;
            }
            catch (ObjectDisposedException)
            {
                return;
            }
            catch (SocketException)
            {
                // One bad datagram must not end the loop.
            }
        }
    }

    public async ValueTask DisposeAsync()
    {
        _loop?.Cancel();
        _client?.Dispose();

        if (_receive is not null)
        {
            try
            {
                await _receive;
            }
            catch (OperationCanceledException)
            {
                // Expected on shutdown.
            }
        }

        _loop?.Dispose();
        _loop = null;
        _client = null;
        _receive = null;
    }
}
```

```csharp
using Mm2Lobby.Core.ZeroTier;

namespace Mm2Lobby.Core.Peers;

/// <summary>
/// Merges the peers heard over UDP with the nodes ZeroTier reports and the
/// names the app remembers, and sorts the result for display.
/// </summary>
public sealed class PeerDirectory
{
    private readonly IZeroTierClient _zeroTier;
    private readonly PeerTable _table;

    public PeerDirectory(IZeroTierClient zeroTier, PeerTable table)
    {
        _zeroTier = zeroTier;
        _table = table;
    }

    public async Task<IReadOnlyList<Peer>> GetPeersAsync(
        string myNodeId,
        IReadOnlyDictionary<string, string> rememberedNames,
        CancellationToken ct)
    {
        var quality = await _zeroTier.GetLinkQualityAsync(ct);
        var peers = new List<Peer>();
        var seen = new HashSet<string>(StringComparer.OrdinalIgnoreCase) { myNodeId };

        foreach (var live in _table.GetLive())
        {
            if (!seen.Add(live.NodeId)) continue;

            peers.Add(new Peer(
                live.NodeId,
                live.Player,
                live.Address,
                IsOnline: true,
                AppRunning: true,
                live.Hosting,
                live.StartedAt,
                quality.TryGetValue(live.NodeId, out var link) ? link : LinkQuality.Unknown));
        }

        foreach (var (nodeId, link) in quality)
        {
            if (!seen.Add(nodeId)) continue;

            peers.Add(new Peer(
                nodeId,
                NameOf(nodeId, rememberedNames),
                Address: null,
                IsOnline: true,
                AppRunning: false,
                Hosting: false,
                StartedAt: null,
                link));
        }

        foreach (var (nodeId, name) in rememberedNames)
        {
            if (!seen.Add(nodeId)) continue;

            peers.Add(new Peer(
                nodeId,
                name,
                Address: null,
                IsOnline: false,
                AppRunning: false,
                Hosting: false,
                StartedAt: null,
                LinkQuality.Unknown));
        }

        return peers
            .OrderByDescending(peer => peer.Hosting)
            .ThenByDescending(peer => peer.AppRunning)
            .ThenByDescending(peer => peer.IsOnline)
            .ThenBy(peer => peer.DisplayName, StringComparer.OrdinalIgnoreCase)
            .ToList();
    }

    private static string NameOf(
        string nodeId, IReadOnlyDictionary<string, string> rememberedNames)
        => rememberedNames.TryGetValue(nodeId, out var name) ? name : nodeId;
}
```

```csharp
using System.Text.Json;

namespace Mm2Lobby.Core.Configuration;

/// <summary>
/// Reads and writes the one configuration file. A missing or malformed file
/// loads the defaults, because a broken file must not stop a race.
/// </summary>
public sealed class ConfigStore
{
    private static readonly JsonSerializerOptions Json = new()
    {
        PropertyNamingPolicy = JsonNamingPolicy.CamelCase,
        WriteIndented = true,
    };

    private readonly string _path;

    public ConfigStore(string path) => _path = path;

    public static string DefaultPath => Path.Combine(
        Environment.GetFolderPath(Environment.SpecialFolder.ApplicationData),
        "Mm2Lobby",
        "config.json");

    public AppConfig Load()
    {
        try
        {
            if (!File.Exists(_path)) return Defaults();

            var config = JsonSerializer.Deserialize<AppConfig>(File.ReadAllText(_path), Json);
            if (config is null) return Defaults();

            if (string.IsNullOrWhiteSpace(config.DisplayName))
            {
                config.DisplayName = Environment.MachineName;
            }

            config.RememberedNames = new Dictionary<string, string>(
                config.RememberedNames, StringComparer.OrdinalIgnoreCase);

            return config;
        }
        catch (Exception e) when (e is JsonException or IOException or UnauthorizedAccessException)
        {
            return Defaults();
        }
    }

    public void Save(AppConfig config)
    {
        var folder = Path.GetDirectoryName(_path);
        if (!string.IsNullOrEmpty(folder)) Directory.CreateDirectory(folder);

        File.WriteAllText(_path, JsonSerializer.Serialize(config, Json));
    }

    private static AppConfig Defaults() => new() { DisplayName = Environment.MachineName };
}
```

```csharp
    {
        _transport.DatagramReceived += OnDatagram;
        await _transport.StartAsync(Port, ct);

        _loop = CancellationTokenSource.CreateLinkedTokenSource(ct);
        _pump = PumpAsync(_loop.Token);
    }

    public async Task RunCycleAsync(CancellationToken ct)
    {
        _status = await _zeroTier.GetStatusAsync(ct);
        _network = await _zeroTier.GetNetworkAsync(_config.ZeroTierNetworkId, ct);

        await AnnounceAsync(ct);

        Peers = await _directory.GetPeersAsync(
            _status?.NodeId ?? string.Empty, _config.RememberedNames, ct);

        RememberNames();
        PeersChanged?.Invoke(Peers);
    }

    public void StartHosting() => _hostingSince = _clock();

    public void StopHosting() => _hostingSince = null;

    private async Task AnnounceAsync(CancellationToken ct)
    {
        if (_status is null || _network?.Address is null) return;

        var announcement = new Announcement
        {
            AppVersion = _appVersion,
            NodeId = _status.NodeId,
            Player = _config.DisplayName,
            Address = _network.Address.ToString(),
            Hosting = IsHosting,
            StartedAt = _hostingSince,
        };

        var destination = IPv4Math.BroadcastAddress(_network.Address, _network.PrefixLength);
        await _transport.SendAsync(announcement.ToBytes(), destination, Port, ct);
    }

    private void OnDatagram(byte[] payload, IPAddress source)
    {
        if (_network?.Address is null) return;

        var allowed = IPv4Math.Subnet(_network.Address, _network.PrefixLength);
        _table.Accept(payload, source, allowed);
    }

    private void RememberNames()
    {
        var changed = false;

        foreach (var peer in Peers.Where(peer => peer.AppRunning))
        {
            if (_config.RememberedNames.TryGetValue(peer.NodeId, out var known)
                && known == peer.DisplayName)
            {
                continue;
            }

            _config.RememberedNames[peer.NodeId] = peer.DisplayName;
            changed = true;
        }

        if (changed) _configStore.Save(_config);
    }

    private async Task PumpAsync(CancellationToken ct)
    {
        using var timer = new PeriodicTimer(CyclePeriod);

        while (!ct.IsCancellationRequested)
        {
            try
            {
                await RunCycleAsync(ct);
                await timer.WaitForNextTickAsync(ct);
            }
            catch (OperationCanceledException)
            {
                return;
            }
        }
    }

    public async ValueTask DisposeAsync()
    {
        _loop?.Cancel();
        _transport.DatagramReceived -= OnDatagram;

        if (_pump is not null)
        {
            try
            {
                await _pump;
            }
            catch (OperationCanceledException)
            {
                // Expected on shutdown.
            }
        }

        _loop?.Dispose();
        await _transport.DisposeAsync();
    }
}
```

```csharp
namespace Mm2Lobby.Core.Preflight;

/// <summary>
/// Runs every check, even after one fails, so the player sees the whole list at
/// once rather than one problem per attempt.
/// </summary>
public sealed class PreflightRunner
{
    private readonly IReadOnlyList<ICheck> _checks;

    public PreflightRunner(IReadOnlyList<ICheck> checks) => _checks = checks;

    public async Task<IReadOnlyList<CheckResult>> RunAllAsync(CancellationToken ct)
    {
        var results = new List<CheckResult>(_checks.Count);

        foreach (var check in _checks)
        {
            try
            {
                results.Add(await check.RunAsync(ct));
            }
            catch (Exception e) when (e is not OperationCanceledException)
            {
                results.Add(new CheckResult(
                    check.Name,
                    CheckStatus.Unavailable,
                    $"The check could not run: {e.Message}",
                    null));
            }
        }

        return results;
    }

    public static bool AllPassed(IReadOnlyList<CheckResult> results)
        => results.Count > 0 && results.All(result => result.Status == CheckStatus.Pass);
}
```

```csharp
using System.Diagnostics;
using Mm2Lobby.Core.Processes;

namespace Mm2Lobby.Windows;

public sealed class SystemProcessRunner : IProcessRunner
{
    private readonly bool _elevate;

    public SystemProcessRunner(bool elevate = false) => _elevate = elevate;

    public async Task<ProcessResult> RunAsync(
        string fileName, string arguments, CancellationToken ct)
    {
        var info = new ProcessStartInfo(fileName, arguments)
        {
            CreateNoWindow = true,
        };

        if (_elevate)
        {
            // An elevated process cannot redirect its streams, so the caller
            // judges it by its exit code alone.
            info.UseShellExecute = true;
            info.Verb = "runas";
        }
        else
        {
            info.UseShellExecute = false;
            info.RedirectStandardOutput = true;
            info.RedirectStandardError = true;
        }

        try
        {
            using var process = Process.Start(info);
            if (process is null) return new ProcessResult(-1, "", "The process did not start.");

            var output = _elevate ? Task.FromResult("") : process.StandardOutput.ReadToEndAsync(ct);
            var error = _elevate ? Task.FromResult("") : process.StandardError.ReadToEndAsync(ct);

            await process.WaitForExitAsync(ct);

            return new ProcessResult(process.ExitCode, await output, await error);
        }
        catch (Exception e) when (e is System.ComponentModel.Win32Exception or FileNotFoundException)
        {
            return new ProcessResult(127, "", e.Message);
        }
    }
}
```

```csharp
        {
```
```csharp
            return Fail(

        }

        return new CheckResult(
            Name, CheckStatus.Pass, $"Connected as {network.Address}.", null);
    }
```

```csharp
        @"SOFTWARE\WOW6432Node\Microsoft\Microsoft Games\Midtown Madness 2";

    private const string Executable = "midtown2.exe";

    private readonly ConfigStore _configStore;
    private readonly Func<string?> _askThePlayer;

    /// <param name="askThePlayer">
    /// Opens a file picker and returns the chosen path, or null when the player
    /// cancels. The WPF project supplies it.
    /// </param>
    public GamePathCheck(ConfigStore configStore, Func<string?> askThePlayer)
    {
        _configStore = configStore;
        _askThePlayer = askThePlayer;
    }

    public string Name => "Midtown Madness 2";

    public Task<CheckResult> RunAsync(CancellationToken ct)
    {
        var config = _configStore.Load();

        if (IsTheGame(config.GamePath))
        {
            return Task.FromResult(Pass(config.GamePath));
        }

        var found = FindInRegistry();
        if (found is not null)
        {
            config.GamePath = found;
            _configStore.Save(config);
            return Task.FromResult(Pass(found));
        }

        return Task.FromResult(new CheckResult(
            Name,
            CheckStatus.Fail,
            $"The app cannot find {Executable}.",
            "Choose the game's executable."));
    }

    public Task<CheckResult> FixAsync(CancellationToken ct)
    {
        var chosen = _askThePlayer();

        if (!IsTheGame(chosen))
        {
            return Task.FromResult(new CheckResult(
                Name,
                CheckStatus.Fail,
                $"That file is not {Executable}.",
                $"Choose {Executable} inside the game's folder."));
        }

        var config = _configStore.Load();
        config.GamePath = chosen!;
        _configStore.Save(config);

        return Task.FromResult(Pass(chosen!));
    }

    private CheckResult Pass(string path)
        => new(Name, CheckStatus.Pass, $"Found at {path}.", null);

    private static bool IsTheGame(string? path)
        => !string.IsNullOrWhiteSpace(path)
            && Path.GetFileName(path).Equals(Executable, StringComparison.OrdinalIgnoreCase)
            && File.Exists(path);

    private static string? FindInRegistry()
    {
        using var key = Registry.LocalMachine.OpenSubKey(RegistryKey);
        if (key is null) return null;

        foreach (var name in key.GetValueNames())
        {
            if (key.GetValue(name) is not string value) continue;

            if (IsTheGame(value)) return value;

            var candidate = Path.Combine(value, Executable);
            if (IsTheGame(candidate)) return candidate;
        }

        return null;
    }
}
```

`src/Mm2Lobby.Windows/Checks/FirewallCheck.cs`:

```csharp
using Mm2Lobby.Core.Preflight;
using Mm2Lobby.Core.Processes;

namespace Mm2Lobby.Windows.Checks;

/// <summary>
/// The most valuable check. When the firewall blocks the game, MM2 fails
/// silently and reports only that it found no host.
/// </summary>
public sealed class FirewallCheck : ICheck
{
    public const string RuleName = "MM2 Lobby - Midtown Madness 2";

    private readonly IProcessRunner _runner;
    private readonly IProcessRunner _elevatedRunner;
    private readonly Func<string> _gamePath;

    public FirewallCheck(
        IProcessRunner runner, IProcessRunner elevatedRunner, Func<string> gamePath)
    {
        _runner = runner;
        _elevatedRunner = elevatedRunner;
        _gamePath = gamePath;
    }

    public string Name => "Windows Firewall";

    public async Task<CheckResult> RunAsync(CancellationToken ct)
    {
        var result = await _runner.RunAsync(
            "netsh.exe", $"advfirewall firewall show rule name=\"{RuleName}\"", ct);

        if (result.Succeeded && result.StandardOutput.Contains(RuleName, StringComparison.Ordinal))
        {
            return new CheckResult(Name, CheckStatus.Pass, "The rule is in place.", null);
        }

        return new CheckResult(
            Name,
            CheckStatus.Fail,
            "No firewall rule allows MM2. Without it the game reports no host and gives no reason.",
            "Add an inbound and an outbound allow rule. This needs administrator rights.");
    }

    public async Task<CheckResult> FixAsync(CancellationToken ct)
    {
        var path = _gamePath();

        if (string.IsNullOrWhiteSpace(path))
        {
            return new CheckResult(
                Name,
                CheckStatus.Fail,
                "The game path is unknown, so the rule cannot name a program.",
                "Run the Midtown Madness 2 check first.");
        }

        foreach (var direction in new[] { "in", "out" })
        {
            var arguments =
                $"advfirewall firewall add rule name=\"{RuleName}\" "
                + $"dir={direction} action=allow program=\"{path}\" enable=yes profile=any";

            var result = await _elevatedRunner.RunAsync("netsh.exe", arguments, ct);

            if (!result.Succeeded)
            {
                return new CheckResult(
                    Name,
                    CheckStatus.Fail,
                    $"netsh exited with code {result.ExitCode} for the {direction} rule.",
                    "Open an administrator command prompt and run: netsh " + arguments);
            }
        }

        return await RunAsync(ct);
    }
}
```

### Task 9: The WPF window

> **Caution:** This task needs a Windows 10 or 11 machine with the .NET 10 SDK. Do not start it on macOS.

> **Caution:** The `MainWindow` code later in this task was written before tasks
> 1 to 6 were built and reviewed. Seven requirements below came out of that work

> wins. Read it before writing any of the window.

**Requirements added after the whole-branch review of tasks 1 to 6**

1. **The window owns the one `AppConfig` instance.** Load it once, pass that
   instance to `LobbyService`'s constructor, and hand the same instance to every
   preflight check. Do not let two components load their own copy. With two
   copies, the player chooses the game, a friend's name arrives two seconds
   later, the lobby saves its stale copy, and the game path is gone — silently,
   on a repeating timer, with a symptom that points nowhere near the cause.
2. **Own the version-mismatch warning.** Spec section 7 requires it and only the
   window can build it. Compare each `Peer.AppVersion` against this app's own
   version and mark any mismatch in the row.
3. **Own the display-name editor.** Spec section 5.8 requires that the player
   can change it, and no other task can. Set `DisplayName` on the shared
   `AppConfig`; the next cycle announces it. Give the text box a `MaxLength` of
   32, because `PeerTable` rejects a longer name and the player would become
   invisible to every friend while their own list looked normal.
4. **Marshal `PeersChanged` to the UI thread.** The service raises it on the
   pump thread, and a WPF binding touched off the UI thread throws.
5. **On "Check again", dispose the service and construct a new one.** Do not
   call `StartAsync` twice — it throws, by the single-use contract — and do not
   call `RunCycleAsync` for a manual refresh.
6. **Show `LastCycleFault`.** It holds the exception from the last failed cycle.
   The app absorbs exceptions at three places and has no logger, so without this
   a friend whose lobby stops working has nothing to tell you.
7. **`CurrentHost` never returns this machine.** Show your own hosting through
   `IsHosting` and `MyAddress`. A row bound to `CurrentHost?.Address` displays
   "no host" while you are hosting.

**The real constructor signatures, after task 8**

The `MainWindow` code later in this task calls three checks with signatures that
no longer exist. Use these. **Every `config` below must be the same `AppConfig`
instance `LobbyService` receives** — that is requirement 1, and these three call
sites are where it is won or lost.

```csharp
new ZeroTierCheck(zeroTier, config)
new GamePathCheck(config, store, GameLocator.FindInRegistry, AskForTheGame)
new FirewallCheck(plainRunner, elevatedRunner, config)
new DirectPlayCheck(elevatedRunner)
```

`ZeroTierCheck` takes the configuration rather than a network-ID string for the
same reason the other two do: a captured string goes stale the moment the
settings screen changes the ID.

**The firewall check needs a Repair action, not only a Fix-on-Fail**

The check cannot see a rule that names a **stale program path**. The player may
move or reinstall MM2. Then the rule exists and the check passes, but the
firewall blocks the game.

`FixAsync` repairs this case. A window that offers Fix only for a failing check
never reaches that repair.

Offer Repair on the firewall row even when it passes. One sentence of hint text
is enough: the rule may name an old copy of the game.

**A second case the check cannot see, and nor can the Repair button.** Windows
itself may hold a **Block** rule for `midtown2.exe`, from a prompt the player
once answered with No. A Block rule overrides every Allow rule, so the check
shows Pass while the game stays blocked. Finding it needs the text of the
`netsh` output, which is localised, so this design cannot detect it. Say so in
the hint text: if MM2 still finds no host after every check passes, the player
should look for a Block rule for `midtown2.exe` in Windows Defender Firewall.

**One thing to verify on the very first Windows run, before anything else**

`zerotier-cli` on Windows is a batch file, and its authentication token is
normally readable only by an administrator. If the player is a standard user,
every ZeroTier call may fail — which would take the whole application down, not
just one check. Confirm this before trusting any other result. If it bites, the
options are to run the app elevated or to place a copy of the token where the
user can read it. The ZeroTier check's failure message names this possibility so
the player is not left guessing.

- [ ] **Step 4: Write the window code**

`src/Mm2Lobby.App/MainWindow.xaml.cs`:

```csharp
using System.Reflection;
using System.Windows;
using Microsoft.Win32;
using Mm2Lobby.Core.Configuration;
using Mm2Lobby.Core.Launch;
using Mm2Lobby.Core.Lobby;
using Mm2Lobby.Core.Peers;
using Mm2Lobby.Core.Preflight;
using Mm2Lobby.Core.ZeroTier;
using Mm2Lobby.Windows;
using Mm2Lobby.Windows.Checks;

namespace Mm2Lobby.App;

public partial class MainWindow : Window
{
    private readonly ConfigStore _configStore = new(ConfigStore.DefaultPath);
    private readonly List<ICheck> _checks = new();
    private LobbyService? _lobby;
    private GameLauncher? _launcher;
    private readonly CancellationTokenSource _shutdown = new();

    public MainWindow()
    {
        InitializeComponent();
        Loaded += OnLoaded;
        Closed += async (_, _) => await ShutDownAsync();
    }

    private async void OnLoaded(object sender, RoutedEventArgs e)
    {
        var config = _configStore.Load();
        var plainRunner = new SystemProcessRunner();
        var elevatedRunner = new SystemProcessRunner(elevate: true);
        var zeroTier = new ZeroTierClient(plainRunner);

        _checks.Add(new ZeroTierCheck(zeroTier, config.ZeroTierNetworkId));
        _checks.Add(new DirectPlayCheck(elevatedRunner));
        _checks.Add(new GamePathCheck(_configStore, AskForTheGame));
        _checks.Add(new FirewallCheck(
            plainRunner, elevatedRunner, () => _configStore.Load().GamePath));

        _launcher = new GameLauncher(new SystemProcessLauncher());

        var table = new PeerTable(LobbyService.PeerExpiry, () => DateTimeOffset.UtcNow);
        _lobby = new LobbyService(
            zeroTier,
            new UdpPeerTransport(),
            table,
            new PeerDirectory(zeroTier, table),
            _configStore,
            Assembly.GetExecutingAssembly().GetName().Version?.ToString() ?? "0.0.0",
            () => DateTimeOffset.UtcNow);

        _lobby.PeersChanged += OnPeersChanged;

        if (!await RunPreflightAsync()) return;

        await _lobby.StartAsync(_shutdown.Token);
    }

    private async Task<bool> RunPreflightAsync()
    {
        var results = await new PreflightRunner(_checks).RunAllAsync(_shutdown.Token);
        var passed = PreflightRunner.AllPassed(results);

        CheckList.ItemsSource = results.Where(r => r.Status != CheckStatus.Pass).ToList();
        PreflightPanel.Visibility = passed ? Visibility.Collapsed : Visibility.Visible;
        PeerGrid.IsEnabled = passed;
        HostButton.IsEnabled = passed;
        JoinButton.IsEnabled = passed;

        return passed;
    }

    private async void OnRecheckClick(object sender, RoutedEventArgs e)
    {
        if (await RunPreflightAsync() && _lobby is not null)
        {
            await _lobby.StartAsync(_shutdown.Token);
        }
    }

    private async void OnFixClick(object sender, RoutedEventArgs e)
    {
        if (sender is not FrameworkElement { Tag: string name }) return;

        var check = _checks.FirstOrDefault(c => c.Name == name);
        if (check is null) return;

        await check.FixAsync(_shutdown.Token);
        await RunPreflightAsync();
    }

    private void OnPeersChanged(IReadOnlyList<Peer> peers)
        => Dispatcher.Invoke(() =>
        {
            PeerGrid.ItemsSource = peers.Select(PeerRow.From).ToList();

            var host = _lobby?.CurrentHost;
            if (_lobby?.IsHosting == true)
            {
                HostAddress.Text = _lobby.MyAddress ?? "";
                Steps.ItemsSource = JoinInstructions.ForHost();
                HostButton.Content = "Stop hosting";
            }
            else if (host?.Address is not null)
            {
                HostAddress.Text = host.Address.ToString();
                Steps.ItemsSource = JoinInstructions.For(host.Address.ToString());
                HostButton.Content = "Host a race";
            }
            else
            {
                HostAddress.Text = "";
                Steps.ItemsSource = null;
                HostButton.Content = "Host a race";
            }

            JoinButton.IsEnabled = host is not null;
        });

    private void OnHostClick(object sender, RoutedEventArgs e)
    {
        if (_lobby is null) return;

        if (_lobby.IsHosting)
        {
            _lobby.StopHosting();
            return;
        }

        _lobby.StartHosting();
        StartTheGame();
    }

    private void OnJoinClick(object sender, RoutedEventArgs e)
    {
        var address = _lobby?.CurrentHost?.Address?.ToString();
        if (address is null) return;

        Clipboard.SetText(address);
        StartTheGame();
    }

    private void StartTheGame()
    {
        var path = _configStore.Load().GamePath;

        try
        {
            _launcher?.Launch(path);
        }
        catch (Exception error)
        {
            MessageBox.Show(
                this, $"MM2 did not start: {error.Message}", "MM2 Lobby",
                MessageBoxButton.OK, MessageBoxImage.Warning);
        }
    }

    private static string? AskForTheGame()
    {
        var picker = new OpenFileDialog
        {
            Title = "Find midtown2.exe",
            Filter = "Midtown Madness 2|midtown2.exe|Programs|*.exe",
        };

        return picker.ShowDialog() == true ? picker.FileName : null;
    }

    private async Task ShutDownAsync()
    {
        _shutdown.Cancel();

        if (_lobby is not null)
        {
            _lobby.PeersChanged -= OnPeersChanged;
            await _lobby.DisposeAsync();
        }

        _shutdown.Dispose();
    }
}
```
